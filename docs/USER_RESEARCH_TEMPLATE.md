# User Research Template

Do not lead participants with the solution. Capture past behavior.

Questions:
1. Have you ever discovered after projection that text in a presentation was difficult to see from farther seats?
2. How did you notice the problem and what did you do?
3. Before presenting, how do you currently decide whether a deck will work in the room?
4. Do you usually get access to the real room before the presentation?
5. Have you ever changed a deck at the last minute because of room/display constraints?
6. If software proposed a change, would you want to approve it before the file is modified?

Record only anonymized participant category/role unless explicit consent is given for attribution. Never fabricate counts or quotes.
